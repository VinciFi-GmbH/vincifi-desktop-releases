# VinciFi Desktop – Releases

Installer und Auto-Update-Feed für **VinciFi Desktop**. Der Quellcode ist privat.

**Neueste Version:** [Releases → Latest](https://github.com/VinciFi-GmbH/vincifi-desktop-releases/releases/latest)

- macOS: `VinciFi_<version>_universal.dmg` öffnen und VinciFi in *Programme* ziehen.
  Beim ersten Start ggf. Rechtsklick → *Öffnen* (die App ist noch nicht notarisiert).
- Windows: `VinciFi_<version>_x64-setup.exe` ausführen.

Danach aktualisiert sich die App selbst: Sie prüft beim Start und alle 6 Stunden auf neue Versionen
und zeigt in der Titelleiste „Update auf vX“ an.
